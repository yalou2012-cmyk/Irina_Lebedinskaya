# Как менять содержание сайта

## Размышления

Откройте папку `data`, затем файл `reflections.js` в Блокноте или текстовом редакторе. Не открывайте его двойным щелчком для запуска — выберите «Открыть с помощью → Блокнот».

Каждая фраза находится на отдельной строке:

```js
  "Что со мной сейчас происходит?",
```

- Чтобы изменить фразу, замените только текст между двумя прямыми кавычками `"`.
- Чтобы добавить фразу, скопируйте целую строку перед закрывающей строкой `];` и напишите свой текст внутри кавычек.
- Чтобы удалить фразу, удалите всю её строку вместе с кавычками и запятой.
- Сохраняйте прямые кавычки с двух сторон и запятую в конце каждой строки. Внутри текста можно использовать русские кавычки «ёлочки».
- Не удаляйте первую строку `const reflections = [` и последнюю строку `];`.
- Сохраните файл в кодировке UTF-8. Оставьте хотя бы одну фразу. Если список пустой, блок не показывается. Если фраза одна, она остаётся на экране без переключения.

Обычная смена происходит примерно каждые 7 секунд. Наведение мыши, касание и работа с кнопками временно останавливают смену. Кнопка «Остановить смену» ставит постоянную паузу, а «Следующая мысль» позволяет переключить текст вручную. При системной настройке уменьшения движения автоматическая смена изначально выключена.

## Изображения

Основные изображения находятся в папке `images`:

- `portrait-hero.jpg` — первый экран;
- `portrait-reflective.jpg` — фотографический переход;
- `portrait-calm.jpg` — раздел об Ирине;
- `concept-human-world.png` — «Видеть человека целиком»;
- `concept-process-illustrated.png` — рисунок «Понять, что происходит»;
- `concept-relationships.png` — рисунок о системе отношений.

Чтобы заменить картинку, сначала сохраните её старую копию вне папки сайта. Подготовьте новую картинку в том же формате (JPG или PNG), с таким же соотношением сторон, и скопируйте её в `images` под точно таким же именем, согласившись на замену. Проверьте, что имя не стало, например, `portrait-hero.jpg.jpg`. В Проводнике включите показ расширений файлов. Простое изменение расширения не преобразует формат картинки.

Откройте `index.html` в браузере и обновите страницу. Если видна старая картинка, нажмите Ctrl+F5. Если новая картинка имеет другие пропорции, попросите обновить размеры в HTML, чтобы она отображалась корректно.

## Заметки и Telegram

На сайте есть отдельный блок «Заметки» со ссылкой на Telegram-группу. Адрес группы указан в `index.html` в двух местах: в блоке «Заметки» и в контактах. Если адрес изменится, замените его в обоих местах.

В блоке «Контакт» есть отдельная кнопка «Написать в Telegram» для личных сообщений Ирине. Её адрес также находится в `index.html` и отличается от ссылки на группу.

Тексты сообщений из группы пока не копируются на сайт автоматически. Ссылка-приглашение не открывает содержание группы для посетителей сайта без вступления. Для показа конкретной записи на сайте понадобится публичная ссылка на неё или отдельный текст и изображение записи.

## Что лучше не трогать

Без необходимости не меняйте `styles.css`, `script.js`, подключения файлов в начале `index.html` и названия папок. Для изменения размышлений нужен только `data/reflections.js`.

## Как обновить опубликованный сайт

Сохранение на компьютере меняет только локальную копию. Для обновления сайта загрузите изменённый файл в ту же папку репозитория GitHub `yalou2012-cmyk/Irina_Lebedinskaya`, в ветку `main`, и сохраните изменения кнопкой Commit changes. Для размышлений сначала откройте папку `data` в репозитории. GitHub Pages затем обновит сайт, адрес останется прежним. Если не уверены, попросите помочь с загрузкой — менять настройки хостинга не нужно.
